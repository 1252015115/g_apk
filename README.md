## 🔬 处理路径

**第一层：静态可见面归零**
权限、组件、包名、资源索引、字节码，全部从「可直接读取」变成「需要特定条件才能还原」。这一层决定了绝大多数静态引擎能不能给出结论。

**第二层：反编译链路切断**
反编译工具需要先完整解包，再逐项解析。产物在解包阶段就让主流工具中断，拿不到可用的工程，也就无法二次打包或抄逻辑。

**第三层：部署阶段隔离**
安装请求发出时系统会做一轮安全判定。海外方案在那一小段窗口内隔离取证通道，判定请求发不出去就不产生拦截结论，装完立即恢复，不影响后续使用。
